# Как внести вклад в translit

Спасибо, что заглянули! translit — учебный проект курса GitHub 2026 JavaRush: код в `src/` — от курса, его не меняем. Вклад здесь — алфавиты, примеры и исправления букв.

## Как предложить алфавит

1. Откройте Issue «Алфавит <название>» по шаблону: какой стандарт транслитерации и откуда таблица.
2. Сделайте форк и ветку от свежей `main`: `alphabet-<имя>`.
3. Новый файл `alphabets/<имя>.json` — копия `alphabets/passport.json` с изменёнными буквами; в `examples` — две-три фразы с ответом.
4. Чтобы попробовать алфавит у себя, поменяйте строку в `translit.config.json`: `{"alphabet": "<имя>"}`. В PR настройку оставьте как была — алфавит по умолчанию меняет владелец.
5. Перед PR — `npm test`: проверяет формат файла и примеры вашего алфавита.

## Ошибка в букве

Сначала Issue по шаблону баг-репорта: слово, что ожидали, что получили, версия translit. Потом ветка `fix-<коротко>` и PR.

## Коммиты и PR

- Сначала Issue, потом PR — со строкой `Closes #<номер Issue>`.
- Сообщения коммитов — Conventional Commits по-русски: `feat: …` — новый алфавит, `fix: …` — исправление.
- Описание PR — по шаблону: что и зачем, как проверено.

## Помощь ИИ

Агента звать можно. В описании PR — что делал ИИ и что вы проверили сами; в коммите — строка `Assisted-by: <агент> (<что делал>)`. На ревью отвечайте сами.
